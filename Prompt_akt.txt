Тип документа: акт выполненных работ.
Извлеки реквизиты акта по каркасу ниже.

{
  "contract_number": "???",
  "contract_date": "???",
  "act_number": "???",
  "act_date": "???",
  "works_amount": "???"
}

Смысл полей:
- contract_number — номер договора
- contract_date — дата договора
- act_number — номер акта выполненных работ
- act_date — дата акта выполненных работ
- works_amount — сумма выполненных работ
